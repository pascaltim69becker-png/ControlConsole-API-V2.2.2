[GERMAN]
UPDATE Information v4.2
Dieses Update bringt die App auf ein neues Level der Benutzerfreundlichkeit. Wir haben das Design-System perfektioniert und die Steuerung der PS3-Funktionen deutlich verbessert.

🛠 Bug Fixes (Fehlerbehebungen)
• Icon-Korrektur: Das App-Icon auf dem Homescreen ist wieder im klassischen Rot (Fix für das Problem mit dem "schwarzen Icon").
• Scrollbarer Changelog: Das Update-Fenster hat nun eine Scroll-Funktion. Auch lange Beschreibungen können jetzt vollständig gelesen werden, ohne dass die Buttons (Download/Später) verschwinden.
• Power-Aktion Fix: Fehlermeldungen beim Ausschalten oder Neustarten der PS3 wurden entfernt (die App erkennt nun, dass die Verbindung durch die Konsole getrennt wurde).
• LED-Logik: Die Auswahl für den LED-Status (Blinken/Ein/Aus) wird jetzt korrekt gesperrt, wenn "Keine Aktion" bei der Farbe gewählt wurde.
• Theme-Synchronisation: Der "SPÄTER"-Button im Update-Menü passt sich jetzt ebenfalls an das gewählte Farb-Thema an.

🚀 Neue Funktionen & Verbesserungen
• Verbesserte Lüftersteuerung: Der Lüfter (webMAN) reagiert jetzt sofort beim Auswählen einer Prozentzahl (kein extra "Senden" mehr nötig).
• Erweitertes Theme-Menü:
• Buttons im Menü zeigen jetzt eine Vorschau der Farbe (farbige Umrandung).
• Der Haupt-Button zeigt jetzt den Namen des aktiven Themes an (z.B. THEMA: BLAU).
• Zusatzfunktionen (Stern-System): Neue oder experimentelle Features sind jetzt mit einem * markiert. Ein Klick auf den großen Stern am Theme-Button zeigt nun eine Info-Erklärung an.
• Hybrid-Branding: Das PS3-Schild-Logo innerhalb der App leuchtet nun passend zum gewählten Farb-Thema.

[ENGLISH]
UPDATE Information v4.2
This update elevates the app with a perfected design system and significantly improved PS3 function controls.

🛠 Bug Fixes
• Icon Fix: Restored the classic Red app icon on the homescreen (resolves the "black icon" issue).
• Scrollable Changelog: The update dialog now features a scrollable text area. Long changelogs can be read fully without hiding the action buttons.
• Power Action Fix: Removed annoying error messages during Shutdown/Reboot (the app now gracefully handles the connection drop).
• LED Logic: The LED status selector is now disabled and greyed out when "No Action" is selected for the color.
• Theme Sync: The "LATER" button in the update dialog now correctly follows the selected color theme.

🚀 New Features & Improvements
•
Immediate Fan Control: Fan speed (webMAN) now executes instantly upon selecting a percentage (no manual "Send" required).
• Enhanced Theme Menu:
• Selection buttons now feature color previews (colored borders).
• The main theme button now displays the active theme name (e.g., THEME: BLUE).
• Extra Features (Star System): New or experimental features are now marked with a *. Tapping the large star icon provides an information popup.
• Dynamic Branding: The PS3 shield logo inside the app now dynamically changes color to match your selected theme.
