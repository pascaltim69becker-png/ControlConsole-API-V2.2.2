
🚀 Changelog – Update v4.5

🇪 DEUTSCH (DE)
Hinweis & Changelog
Version 4.5 (Final Release)
Created by: DEX MoDz | Baujahr: 2026
NEUERUNGEN IN VERSION 4.5:
• Matrix Hacker Animation: Dynamische Binärcode-Animation (100110...) im Hintergrund – die Farbe passt sich automatisch dem gewählten Theme bzw. deiner Custom-Farbe an!
• Animierte Dialoge: Neue Aufplopp- & Pulsier-Animation für das Kreuz im Shutdown-Fenster sowie eine Schließ-Animation für das Schloss im Banned-Fenster.
• Live GitHub Synchronisation: Zuverlässige Abfrage von App-Shutdown (app_shutdown) & Hardware-Sperren direkt von GitHub beim App-Start.
• Komplette Mehrsprachigkeit: Volle Übersetzung für Deutsch (DE), Englisch (EN) und Französisch (FR) auf allen Menüs, Dialogen & Buttons.
• Stabilitäts- & Bugfixes: Behebung potenzieller Abstürze (NullPointer-Schutz) und Performance-Optimierungen.

🇬🇧 ENGLISCH (EN)
Note & Changelog
Version 4.5 (Final Release)
Created by: DEX MoDz | Year: 2026
